# 📦 Gestion de Matériel Informatique

Application web de gestion de matériel informatique avec affectation aux directions et portes.

---

## 🛠 Technologies
- **Frontend** : React, Material UI
- **Backend** : Node.js, Express
- **Base de données** : MySQL
- **Authentification** : JWT

---

## ✅ Prérequis
- Node.js v18+
- MySQL v8+
- npm v9+

---

## 📂 Structure
- `frontend/` : application React
- `backend/` : API Node / Express

---

## ▶️ Lancement du projet

### Backend
```bash
cd backend
npm install
npm start 
```

### Frontend
```bash
cd frontend
npm install
npm start
```

### Fonctionnalités
- Gestion des matériels
- Affectation / désaffectation
- Gestion des directions et portes
- Authentification utilisateur
